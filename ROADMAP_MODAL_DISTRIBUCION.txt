💾 5. REDISTRIBUCIÓN MANUAL

🏗️ ARQUITECTURA DEL SISTEMA
===============================================================================

FRONTEND (JavaScript - reclutas.js)
├── openDistribucionExcelModal()      → Crea y abre modal
├── setupDistribucionModalEvents()    → Configura eventos
├── handleDistribucionExcelFile()     → Valida archivo
├── executeDistribucionExcel()        → Envía al servidor
├── showDistribucionProgress()        → Progress bar
├── showDistribucionResults()         → Muestra resultados
├── saveAsesorDistribution()          → Redistribuye manual
└── resetDistribucionModal()          → Resetea modal

BACKEND (Python Flask - api.py)
├── /reclutas/distribuir-excel        → Procesa Excel inicial
├── /reclutas/redistribuir-manual     → Redistribución manual
└── /reclutas/lote-reciente          → Obtiene lote reciente

HELPERS (Python - helpers.py)
└── procesar_y_distribuir_excel()     → Lógica de procesamiento

===============================================================================
🎨 INTERFAZ DE USUARIO
===============================================================================

MODAL STRUCTURE
- Header: Título con ícono
- Body: 
  * Información del proceso
  * Drop zone para archivo
  * Progress bar
  * Resultados y estadísticas
- Footer: Botones de acción

ESTADOS DEL MODAL
1. Inicial: Drop zone visible
2. Archivo Seleccionado: Muestra info del archivo + botón "Confirmar"
3. Procesando: Progress bar animado
4. Resultados: Tabla editable + botón "Guardar Cambios"

===============================================================================
⚡ FLUJO DE TRABAJO
===============================================================================

DISTRIBUCIÓN AUTOMÁTICA
1. Usuario selecciona archivo Excel
2. Validación del archivo (formato, tamaño)
3. Envío al backend con FormData
4. Procesamiento y distribución equitativa
5. Visualización de resultados

REDISTRIBUCIÓN MANUAL
1. Usuario modifica cantidades en la tabla
2. Marca/desmarca asesores como "fijos"
3. Clic en "Guardar Cambios"
4. Recálculo y reasignación de reclutas
5. Actualización de la vista

===============================================================================
🔧 VALIDACIONES Y CONTROLES
===============================================================================

VALIDACIONES FRONTEND
- Formato de archivo (.xlsx, .xls)
- Tamaño máximo (10MB)
- Campos numéricos en inputs
- Datos válidos para guardar

VALIDACIONES BACKEND
- Headers Excel requeridos
- Duplicados de teléfono
- Asesores activos disponibles
- Permisos de usuario (admin/gerente)

===============================================================================
📈 MÉTRICAS Y ESTADÍSTICAS
===============================================================================

ESTADÍSTICAS MOSTRADAS
- Total reclutas procesados
- Reclutas exitosos
- Errores encontrados
- Distribución por asesor
- Promedio de asignación

ESTADOS DE ASESORES
- Fijos: Mantienen su asignación
- Flexibles: Se redistribuyen automáticamente
- Activos: Disponibles para asignación

🎯 CASOS DE USO

1. CARGA MASIVA

   - Procesamiento automático y distribución

2. DISTRIBUCIÓN EQUITATIVA

3. AJUSTE MANUAL

   - Marcar asesores como fijos o flexibles

4. SEGUIMIENTO
   - Ver estadísticas de distribución
   - Monitorear errores y éxitos

5. ERROR HANDLING
   - Gestionar duplicados y errores de formato
   - Mostrar detalles específicos de errores
