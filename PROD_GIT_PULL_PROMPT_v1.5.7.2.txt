TROUBLESHOOTING
=============================================================================
A) Error de autenticacion en git pull:
   git remote set-url origin https://<TOKEN>@github.com/smookymolina/template_app.git
   git remote -v   # verificar

B) Error 500 despues del pull:
   sudo chown -R www-data:www-data /var/www/template_app/instance/
   sudo chown -R www-data:www-data /var/www/template_app/uploads/
   sudo systemctl restart gunicorn

C) "table already exists" al ejecutar flask db upgrade:
   # La tabla ya fue creada por db.create_all (normal en este proyecto).
   # Marcarla como aplicada sin ejecutar:
   flask db stamp f3a9b2c1d0e4
   # Verificar:
   flask db current

D) Los checkboxes no aparecen en el formulario del evento (solo dice "Sin documentos"):
   - Verificar que el recluta tiene documentos subidos en "Gestion de Documentos"
   - Verificar en consola del navegador: debe cargar GET /api/reclutas/{id}/documentos (200)
   - Si hay error 500: revisar que la tabla evento_recluta_documento existe (PASO 4C)

E) En el portal publico solo aparece 1 documento (el primero):
   - Limpiar cache del navegador (Ctrl+Shift+R) — puede estar usando JS viejo
   - Verificar que client.js carga la version nueva (Network tab -> client.js -> sin 304 viejo)
   - Verificar respuesta de /api/tracking/{folio}/timeline: debe incluir "documentos": [{...},{...}]

F) Migracion de datos legacy no se ejecuto (eventos viejos sin documentos en la nueva tabla):
   # Ejecutar migracion manual de datos:
   sqlite3 instance/template_app.db \
     "INSERT OR IGNORE INTO evento_recluta_documento (evento_id, documento_id)
      SELECT id, documento_id FROM evento_recluta WHERE documento_id IS NOT NULL;"
   echo "Migracion manual completada"

G) CSS o JS con cache viejo:
   sudo rm -rf /var/cache/nginx/*
   sudo systemctl restart nginx
   # Hard refresh: Ctrl+Shift+R

H) Error de autenticacion en git pull:
   git remote set-url origin https://<TOKEN>@github.com/smookymolina/template_app.git

I) Panel de Gerente no muestra reclutas:
   - Verificar que main.js incluya handleGerentePanelSection() y
     el case en handleSpecialSections('gerente-panel-section')
   - Hard refresh del navegador (Ctrl+Shift+R) para evitar JS cacheado
