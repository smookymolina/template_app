Problema: Error en el tutorial de seguimiento al pasar al paso 3.

Descripción del Error:
Al intentar avanzar al paso 3 del tutorial en la página de seguimiento (/seguimiento), el tutorial se detiene abruptamente. Si se vuelve a hacer clic en el botón "Siguiente", el tutorial finaliza.

Análisis del Problema:
1.  El tutorial de seguimiento está definido en `static/js/tutorial.js` en el array `publicSteps`.
2.  El paso 3 del tutorial tiene como objetivo el elemento `#forgot-folio-link`.
3.  La función `showStep()` en `tutorial.js` es responsable de mostrar cada paso. Esta función busca el elemento objetivo (`targetElement`) usando `document.querySelector(step.target)`.
4.  Se identificó que si `targetElement` no se encuentra (es `null`), la función `showStep()` simplemente registra una advertencia y retorna, deteniendo el flujo del tutorial en ese punto.
5.  Aunque el elemento `#forgot-folio-link` existe en `templates/seguimiento.html`, la causa probable del error es un problema de temporización. Es decir, el script de JavaScript intenta acceder al elemento antes de que el DOM lo haya renderizado completamente o antes de que esté disponible en la página.
6.  Cuando el usuario vuelve a hacer clic en "Siguiente" después de que el tutorial se detiene, el `currentStep` se incrementa, y como el paso 4 no existe, el tutorial asume que ha terminado y llama a la función `complete()`, lo que lo finaliza.

Solución Propuesta e Implementada:
Se modificó la función `showStep()` en `static/js/tutorial.js` para que, si el `targetElement` no se encuentra inmediatamente, utilice la función `waitForElement()` (ya existente en el script) para esperar a que el elemento aparezca en el DOM. Una vez que el elemento es detectado, `showStep()` se vuelve a llamar para el mismo paso, permitiendo que el tutorial continúe correctamente.

Cambio Específico en `static/js/tutorial.js`:

Antes:
```javascript
        if (!targetElement) {
            console.warn(`⚠️ Elemento no encontrado: ${step.target}, no se puede mostrar el paso.`);
            return; // Do not call nextStep here to avoid infinite loops if element is persistently missing
        }
```

Después:
```javascript
        if (!targetElement) {
            console.warn(`⚠️ Elemento no encontrado: ${step.target}. Esperando a que aparezca...`);
            // Use waitForElement to wait for the target to appear
            this.waitForElement(step.target, () => {
                // Once the element is found, re-call showStep for the current step
                this.showStep(stepIndex);
            });
            return; // Exit to prevent further processing until element is found
        }
```
