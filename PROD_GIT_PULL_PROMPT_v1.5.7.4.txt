   # -------------------------------------------------------

   # MySQL (si aplica):

   # 1B) ARCHIVOS SUBIDOS (fotos y documentos)
   # -------------------------------------------------------
   tar -czf "$BACKUP_DIR/uploads.tar.gz" uploads/
   echo "[OK] Uploads respaldados"

   # 1C) ESTADO DE MIGRACIONES
   # -------------------------------------------------------
   source .venv/bin/activate
   flask db current > "$BACKUP_DIR/db_current.txt" 2>&1 || \
     echo "No migrations applied" > "$BACKUP_DIR/db_current.txt"
   echo "[OK] Estado de migraciones guardado"

   # 1D) EXPORT DE DATOS CSV (recomendado)
   # -------------------------------------------------------

     LATEST=$(ls -dt backup_* 2>/dev/null | head -1) && \

   # VERIFICAR QUE EL BACKUP EXISTE ANTES DE CONTINUAR
   ls -lh "$BACKUP_DIR"
   echo ""
   echo "===> BACKUP COMPLETO EN: $BACKUP_DIR <=="
   echo "===> CONTINUA SOLO SI VES LOS ARCHIVOS ARRIBA <=="

TROUBLESHOOTING
=============================================================================
A) Error de autenticacion en git pull:
   git remote set-url origin https://<TOKEN>@github.com/smookymolina/template_app.git
   git remote -v   # verificar

B) Error 500 despues del pull:
   sudo chown -R www-data:www-data /var/www/template_app/instance/
   sudo chown -R www-data:www-data /var/www/template_app/uploads/
   sudo systemctl restart gunicorn

C) La app sigue en modo claro despues del pull (cache de CSS/JS):
   sudo rm -rf /var/cache/nginx/*
   sudo systemctl restart nginx
   # En el navegador: Ctrl+Shift+R (hard refresh)
   # Si persiste: DevTools > Network > "Disable cache" marcado

D) El modo oscuro parpadea al cargar (FOUC):
   - Verificar que templates/base.html tiene el script inline en el <head>
     antes del </head>
   - El script debe estar ANTES de cualquier link CSS
   grep -A5 "prevenir Flash" /var/www/template_app/templates/base.html

E) El color de acento secundario no persiste:
   - Verificar en consola del navegador que CONFIG.STORAGE_KEYS tiene la
     clave de acento secundario definida
   - Limpiar localStorage del navegador y volver a configurar:
     localStorage.clear() en consola (pierdes todas las preferencias)

F) Las tablas de reclutas no se vuelven tarjetas en movil:
   - Verificar que admin-reclutas-management.css se carga (Network tab)
   - Verificar que las filas generadas por JS incluyen data-label en los <td>
   - Hard refresh: Ctrl+Shift+R para descartar JS cacheado

G) Campo fecha_registro da error 422 al guardar recluta:
   - Verificar que el valor enviado es formato YYYY-MM-DD o vacio/null
   - Revisar logs de gunicorn:
     sudo journalctl -u gunicorn --no-pager -n 50

H) Redis no responde:
   sudo systemctl start redis
   redis-cli ping   # debe responder PONG

I) CSS o JS con cache viejo (general):
   sudo rm -rf /var/cache/nginx/*
   sudo systemctl restart nginx
   # Hard refresh: Ctrl+Shift+R

J) Panel de Gerente no muestra reclutas (herencia de v1.5.7.2):
   - Verificar que main.js incluya handleGerentePanelSection()
   - Hard refresh del navegador (Ctrl+Shift+R)
