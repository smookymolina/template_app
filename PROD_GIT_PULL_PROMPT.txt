CHANGES IN THIS VERSION (1.5.6.8 - 2026-01-30):
=============================================================================
1) TRACKING DE TIEMPO DE USO ACTIVO (Activity Tracker):
   - PROBLEMA RESUELTO: El contador de tiempo de sesión contaba infinitamente
     mientras la sesión estaba abierta, sin importar si el usuario estaba
     usando la app o no.

   - SOLUCIÓN: Ahora solo se cuenta el tiempo cuando el usuario está
     ACTIVAMENTE usando la app (clicks, scroll, teclas, movimiento del mouse).

   - IMPLEMENTACIÓN (5 pasos):

     PASO 1 - Modelo UserSession actualizado (models/user_session.py):
       * Nuevo campo: active_time_seconds (tiempo activo acumulado)
       * Nuevo campo: last_heartbeat (timestamp del último heartbeat)
       * Nuevo método: register_activity_heartbeat()
       * Nueva propiedad: active_time_formatted

     PASO 2 - Nuevo endpoint (routes/auth.py):
       * POST /auth/activity-heartbeat
       * Recibe "latidos" del frontend cuando hay actividad
       * Solo acumula tiempo si hay interacción continua

     PASO 3 - Tracker JavaScript (static/js/activity-tracker.js):
       * Detecta eventos: clicks, scroll, teclas, movimiento del mouse
       * Envía heartbeats cada 30 segundos SOLO cuando hay actividad
       * Se detiene si el usuario está inactivo por 60 segundos
       * Se pausa cuando la pestaña está en segundo plano

     PASO 4 - Cálculo de tiempo actualizado (routes/admin.py):
       * _session_duration_minutes() usa active_time_seconds si existe
       * _get_usuarios_online() muestra tiempo activo real
       * Fallback al cálculo legacy para sesiones antiguas

     PASO 5 - Integración (templates/base.html, static/js/auth.js):
       * Script incluido en base.html
       * Se inicia automáticamente al verificar autenticación

   - FILES MODIFIED:
     * models/user_session.py - Nuevos campos y métodos
     * routes/auth.py - Nuevo endpoint activity-heartbeat
     * routes/admin.py - Cálculos actualizados para tiempo activo
     * static/js/activity-tracker.js - NUEVO ARCHIVO
     * static/js/auth.js - Inicialización del tracker
     * templates/base.html - Inclusión del script

TROUBLESHOOTING:
=============================================================================
A) Error 500 después de git pull:
   - CAUSA MÁS COMÚN: Permisos de archivos
   - SOLUCIÓN:
     sudo chown -R www-data:www-data /var/www/template_app/instance/
     sudo chown -R www-data:www-data /var/www/template_app/uploads/
     sudo systemctl restart gunicorn

B) Error "no such column: user_session.active_time_seconds":
   - CAUSA: Las nuevas columnas no se agregaron a la base de datos
   - SOLUCIÓN: Ejecutar paso 6 (agregar columnas SQL)

C) Activity Tracker no funciona:
   - Verificar que el script está cargado:
     DevTools -> Network -> activity-tracker.js (debe dar 200 OK)
   - Verificar consola por errores JavaScript
   - Verificar que el endpoint funciona:
     curl -X POST https://tu-dominio/auth/activity-heartbeat \
       -H "Content-Type: application/json" \
       -d '{"heartbeat_interval": 30}'
     (Debe retornar error de sesión, no error 500)

D) CSS/Styles not updating (old design showing):
   - Clear browser cache (Ctrl+Shift+R or Ctrl+F5)
   - Clear Nginx cache:
     sudo rm -rf /var/cache/nginx/*
     sudo systemctl restart nginx

E) User Activity showing "Modo demostración" (yellow badge):
   - Check endpoint works: curl -I https://tu-dominio/admin/metricas/actividad-usuarios
   - Review server logs for errors:
     sudo journalctl -u gunicorn -n 100 --no-pager | grep -i "actividad\|error"
   - Verify UserSession table has new columns (paso 6)

F) El tiempo de usuarios sigue contando infinitamente:
   - Asegurarse de que el navegador tiene caché limpio (Ctrl+Shift+R)
   - Verificar que activity-tracker.js está cargado (Network tab)
   - Las sesiones ANTIGUAS seguirán mostrando el cálculo legacy
   - Las sesiones NUEVAS mostrarán el tiempo activo real

NOTES:
- REDIS_URL must point to your Redis instance (local or cloud).
- In production, Redis must always be running.
- Static files (CSS, JS, images) may be cached by Nginx or browser.
- After CSS changes, always clear caches and hard refresh.
- If anything fails, use backups in /var/backups/template_app/$TS.
- El Activity Tracker solo rastrea tiempo cuando la pestaña está VISIBLE y
  el usuario está ACTIVO (clicks, scroll, teclas).

  que el usuario inicie una nueva sesión.
