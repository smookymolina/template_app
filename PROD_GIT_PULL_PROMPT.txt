PASO 1: BACKUP COMPLETO DE DATOS (CRITICO - HACER PRIMERO)
=============================================================================
   Este paso es OBLIGATORIO. Sin backup, NO continuar.

   cd /var/www/template_app
   TS=$(date +%Y%m%d_%H%M%S)
   BACKUP_DIR=/var/backups/template_app/$TS
   mkdir -p "$BACKUP_DIR"

   # 1A) Backup de base de datos (PRIORIDAD MAXIMA)
   # -----------------------------------------------
   # SQLite:
   cp instance/template_app.db "$BACKUP_DIR/template_app.db"

   # Actualizar permisos de la BD antes de continuar
   sudo chown www-data:www-data instance/template_app.db
   sudo chmod 664 instance/template_app.db

   # MySQL (alternativa):
   # set -a && [ -f .env ] && . ./.env && set +a
   # mysqldump -u "${MYSQL_USER}" -p"${MYSQL_PASSWORD}" -h "${MYSQL_HOST}" "${MYSQL_DB}" > "$BACKUP_DIR/db.sql"

   # 1B) Backup de archivos subidos (fotos, documentos)
   # ---------------------------------------------------
   tar -czf "$BACKUP_DIR/uploads.tar.gz" uploads/

   # 1C) Backup de estado de migraciones
   # ------------------------------------
   source .venv/bin/activate
   flask db current > "$BACKUP_DIR/db_current.txt" 2>&1 || echo "No migrations" > "$BACKUP_DIR/db_current.txt"

   # 1D) Export de datos a CSV (opcional pero recomendado)
   # ------------------------------------------------------
   python scripts/export_data.py 2>/dev/null && \
   LATEST=$(ls -dt backup_* 2>/dev/null | head -1) && \
   [ -n "$LATEST" ] && mv "$LATEST" "$BACKUP_DIR/"

   # Verificar que el backup existe
   ls -la "$BACKUP_DIR"
   echo "Backup completo en: $BACKUP_DIR"

TROUBLESHOOTING:
=============================================================================
A) Error 500 despues de git pull:
   - CAUSA: Permisos de archivos
   - SOLUCION:
     sudo chown -R www-data:www-data /var/www/template_app/instance/
     sudo chown -R www-data:www-data /var/www/template_app/uploads/
     sudo systemctl restart gunicorn

B) Error "no such column: user_session.active_time_seconds":
   - CAUSA: Columnas no agregadas
   - SOLUCION: Ejecutar paso 4C

C) Fotos no se ven / broken images:
   - Verificar permisos de uploads/
   - Limpiar cache del navegador (Ctrl+Shift+R)

D) Lightbox no funciona:
   - Limpiar cache del navegador
   - Verificar que photo-cropper.js carga (Network tab -> 200 OK)
   - Verificar consola por errores JavaScript

E) Activity Tracker no registra tiempo:
   - Verificar columnas en user_session (paso 4C)
   - Verificar que activity-tracker.js carga correctamente

F) CSS/estilos antiguos:
   - Limpiar cache Nginx: sudo rm -rf /var/cache/nginx/*
   - Reiniciar Nginx
   - Hard refresh en navegador (Ctrl+Shift+R)

G) ROLLBACK (si algo falla):
   - Restaurar base de datos:
     cp "$BACKUP_DIR/template_app.db" instance/template_app.db
   - Restaurar uploads:
     tar -xzf "$BACKUP_DIR/uploads.tar.gz" -C /
   - Regresar a version anterior:
     git checkout <branch-anterior>
   - Reiniciar servicios
