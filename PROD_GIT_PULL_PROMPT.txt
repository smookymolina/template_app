4) ===== CRITICAL: INSTALL AND VERIFY DEPENDENCIES =====

   A) ACTIVATE VIRTUAL ENVIRONMENT FIRST:
      - source venv/bin/activate (Linux/Mac)
      - OR: source .venv/bin/activate
      - OR: .\venv\Scripts\activate (Windows)
      - Verify activation: which python (should point to venv)

   B) INSTALL PYTHON DEPENDENCIES:
      - Upgrade pip first (prevents many issues):
        - python -m pip install --upgrade pip
      - Install requirements with verbose output:
        - python -m pip install -r requirements.txt --no-cache-dir 2>&1 | tee pip_install.log
      - Check exit code: echo $? (must be 0)
      - If install fails, check common issues:
        - Missing system packages: sudo apt install python3-dev libmysqlclient-dev build-essential
        - Permission issues: use --user flag or fix venv ownership
        - Compilation errors: install gcc, make, and development headers

   C) VERIFY CRITICAL PACKAGES ARE INSTALLED:
      - Check Flask and extensions:
        - python -c "import flask; print(f'Flask {flask.__version__}')"
        - python -c "import flask_login; print('flask_login OK')"
        - python -c "import flask_migrate; print('flask_migrate OK')"
      - Check Redis client:
        - python -c "import redis; print(f'redis-py {redis.__version__}')"
      - Check Database drivers:
        - python -c "import pymysql; print(f'PyMySQL {pymysql.__version__}')"
        - python -c "import sqlalchemy; print(f'SQLAlchemy {sqlalchemy.__version__}')"
      - Check other critical imports:
        - python -c "from app_factory import create_app; print('app_factory OK')"
      - If ANY import fails, DO NOT PROCEED - fix the dependency first!

   D) QUICK DEPENDENCY HEALTH CHECK (run this single command):
      - python -c "
import sys
failed = []
for mod in ['flask', 'flask_login', 'flask_migrate', 'redis', 'pymysql', 'sqlalchemy', 'gunicorn']:
    try:
        __import__(mod)
        print(f'✓ {mod}')
    except ImportError as e:
        print(f'✗ {mod}: {e}')
        failed.append(mod)
if failed:
    print(f'\n❌ FAILED: {failed}')
    sys.exit(1)
print('\n✅ All critical dependencies OK')
"

   E) RUN DATABASE MIGRATIONS:
      - flask db upgrade 2>&1 | tee migration.log
      - Check exit code: echo $? (must be 0)
      - If migration fails:

        - Check for pending migrations: flask db history

5) ===== CRITICAL: VERIFY AND START REQUIRED SERVICES =====

   A) CHECK AND START REDIS:
      - Check Redis status:
        - systemctl status redis (or redis-server)
        - OR: docker ps | grep redis
      - If Redis is NOT running, START IT:
        - sudo systemctl start redis
        - OR: sudo systemctl start redis-server
        - OR: docker start redis
        - OR: redis-server --daemonize yes
      - Verify Redis is responding:
        - redis-cli ping
        - Expected response: PONG
      - If Redis fails to start, check logs:
        - sudo journalctl -u redis -n 50
        - OR: cat /var/log/redis/redis-server.log

   B) CHECK AND START MYSQL/MARIADB:
      - Check MySQL status:
        - systemctl status mysql (or mariadb or mysqld)
        - OR: docker ps | grep mysql
      - If MySQL is NOT running, START IT:
        - sudo systemctl start mysql
        - OR: sudo systemctl start mariadb
        - OR: docker start mysql
      - Verify MySQL is responding:
        - mysqladmin ping -u root -p
        - OR: mysql -u root -p -e "SELECT 1"
      - If MySQL fails, check logs:
        - sudo journalctl -u mysql -n 50

   C) CLEAR APPLICATION CACHES (important after deployment):
      - Clear Redis metrics cache:
        - redis-cli KEYS "metrics_cache_*" | xargs redis-cli DEL
        - OR from Python: flask shell -> from utils.metrics_cache import clear_all_metrics_cache; clear_all_metrics_cache()
      - Clear any session caches if needed.

10) TROUBLESHOOTING 502 ERRORS:
   If you see 502 Bad Gateway after deployment:

   A) Check if the application is running:
      - systemctl status gunicorn (or your app service)
      - ps aux | grep gunicorn
      - ps aux | grep python

   B) Check if Redis is running (REQUIRED for metrics):
      - redis-cli ping
      - If no response: sudo systemctl start redis

   C) Check if MySQL is running:
      - mysqladmin ping
      - If no response: sudo systemctl start mysql

   D) Check application logs for errors:
      - sudo journalctl -u gunicorn -n 100
      - Look for: ConnectionRefusedError, redis.exceptions.ConnectionError, OperationalError

   E) CHECK FOR MISSING DEPENDENCIES (common cause of 502):
      - Activate venv: source venv/bin/activate
      - Test imports:
        - python -c "from app_factory import create_app; print('OK')"
      - If ImportError appears:
        - Reinstall: pip install -r requirements.txt --no-cache-dir
        - Check specific package: pip show <package-name>
      - Common missing packages that cause 502:
        - redis, pymysql, gunicorn, flask-login, flask-migrate

   F) Restart in correct order:
      1. sudo systemctl start redis
      2. sudo systemctl start mysql
      3. source venv/bin/activate && pip install -r requirements.txt
      4. sudo systemctl restart gunicorn
      5. Wait 10 seconds
      6. Test: curl -I https://freted.info
